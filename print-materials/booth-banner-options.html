Booth banner — three options to choose from

All three are 72″ × 24″ (6ft × 2ft), shown here scaled down. The dashed line is the safe area — nothing important crosses it, so hems and grommets can't eat any text.

No QR code on the banner, on purpose — a code hanging behind your table is too far away for phones to read. The QR lives on the table sign (table-sign.html), where people can reach it.

Pick one, then tell Claude which — the others get deleted and the winner becomes booth-banner.html.

To make the print file: File → Print → Destination Save as PDF → Paper size 72 × 24 in (or “Custom”) → Margins None → tick Background graphics → Save. If the printer asks for bleed, tell them to add 0.25″ each side — there's plenty of colour to pull from.

Option 1 — Business-card style The look you remembered: your Ocean Daisy photo full-bleed behind the rainbow wordmark, matching the business cards. Warmest and most “you” — but read the photo note first.
Photo note — this one needs a bigger photo file. The copy of IMG_3091.jpeg in the website folder is 1384 × 1500 pixels. That is plenty for a business card, but stretched across 6 feet it works out to only about 19 dots per inch — it will look soft close up. Fix: open the original in Photos, choose File → Export → Export Unmodified Original, and give Claude the file. Straight off your phone it is likely around 3000 pixels wide, which is roughly 42 dots per inch at this size — normal and acceptable for a vinyl banner seen from a few feet away.

This only affects Option 1. Option 2 uses the same photo inside 8.4″ circles (about 165 dots per inch) and the table sign uses it at 207 dots per inch — both are already sharp.
