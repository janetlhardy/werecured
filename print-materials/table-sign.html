Table sign — 5″ × 7″

This is the sign that actually gets scanned. It stands on the table in a cheap acrylic photo holder, where people can reach it — a QR code up on the banner behind you is too far away for phones to read.

Two versions, same wording. Print Version B — the plain dark one. Version A uses the same coaster photo as the booth banner if you would rather they matched. The dashed line is the trim line — the design runs past it on purpose (that's “bleed”), so there are no white slivers if the cut is slightly off.

To print at home: File → Print → Paper Letter → Scale Fit to page → tick Background graphics → print on card stock, then trim to 5 × 7.
To order it printed: Save as PDF at 5.25 × 7.25 in, margins None, and order a 5 × 7 flat card — same as the thank-you cards.
